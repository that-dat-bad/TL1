# 加点項目
* ローダーと配置
* コライダーをゲーム側当たり判定に適用
* 無効フラグの追加（チェックボックス）
* Terrain（地形）の配置

# 独自実装
* CPUマルチコア並列チャンクエクスポート
  * 巨大メッシュを500m単位に自動分割しバックグラウンドBlenderプロセス群で高速並列OBJ出力
* スプライン道路および交差点生成
  * 3Dカーブに沿った車線・白線マテリアル付き道路と十字路・T字・Y字交差点の自動生成
* プロシージャル建築生成
  * Geometry Nodesによる住宅・高層ビル・雑居ビル・タワー・屋根スタイル・セットバックの自動生成
* エージェント型都市レイアウト自動生成
  * RoadAgent成長シミュレーション・BSP区画分割・ボロノイ地価計算による都心〜郊外の自動ゾーニング
* ローカルLLM (Ollama) によるAI自然言語地形生成
  * 日本語プロンプトから道路・山脈スプラインおよび地形パラメータを非同期で自動生成
* Blender MCP (Model Context Protocol) サーバー連携
  * 外部AIエージェントからHTTP/JSON API経由でBlenderの地形やスプラインをリアルタイム遠隔操作
* コライダーの3DビューポートリアルタイムGPU描画
  * GPUシェーダーを用いて3Dビューポート上にコライダーのワイヤーフレームギズモを表示
